Conoce UniversoHéroes

UniversoHéroes es una aplicación web creada para explorar información de diferentes superhéroes de una manera sencilla, visual e interactiva.

Un espacio para los amantes de los superhéroes

Nuestro objetivo es ofrecer un catálogo visual donde los usuarios puedan conocer diferentes personajes y descubrir sus características, habilidades y datos biográficos.

Para desarrollar esta aplicación utilizamos Angular y una API pública de superhéroes, permitiendo obtener la información de los personajes de forma dinámica.

El proyecto fue desarrollado aplicando componentes, rutas, servicios, consumo de API y buenas prácticas de desarrollo web.
